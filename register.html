Youtoken 注册与创建密钥

注册账号 → 创建密钥 → 选择分组 → 获取可用的 API Key

注册账号 创建密钥 选择分组 解释说明
1

注册账号并输入邀请码

第一步是注册 Youtoken 账号，获得使用资格。

a打开注册页面

访问 Youtoken 官网，点击页面上的 「注册」 按钮，进入注册流程。

b填写注册信息

输入你的邮箱地址，设置密码。建议使用常用邮箱，方便后续找回密码和接收通知。

c输入邀请码

在注册表单中找到 「邀请码」 一栏，填入你获得的邀请码。邀请码通常由推荐人或官方活动提供，填写后双方都可获得额外奖励。

💡 邀请码不是必填项，但填写后你和推荐人都能获得返利奖励，建议填上。

d完成注册

点击 「注册」 按钮提交。注册成功后自动登录，进入仪表盘页面。接下来去充值一些余额（支持支付宝），按量计费、余额永久有效。

2

创建 API 密钥

密钥是你调用 API 的凭证，相当于你的专属通行证。

a进入密钥管理页

登录后，在左侧导航栏点击 「API 密钥」（钥匙图标）。首次进入时页面会显示「暂无 API 密钥」。

b点击「创建密钥」

点击页面中央的 「+ 创建密钥」 绿色按钮，弹出创建密钥对话框。

c填写密钥名称

在 「名称」 栏输入一个便于识别的名称，例如 claude-desktop 或 我的主密钥。名称只用于区分不同密钥，随便起即可。

3

选择分组

分组决定你使用的渠道类型、稳定性和价格，是最关键的选择。

a在创建密钥对话框中选择分组

点击 「分组」 下拉菜单，会展示所有可选分组。每个分组后面标注了 倍率（倍率越低价格越便宜）。

b根据需求选择合适的分组

不同分组在价格、渠道质量、并发能力、模型覆盖上有差异。

4

解释说明

"逆向"和"满血"是什么意思？

指模型能力的技术来源不同，直接决定稳定性和使用体验：

  • 逆向渠道：通过第三方账号池或客户端接口间接获取模型能力
    • 存在第三方 system prompt，表现上会存在降智现象
    • 缓存命中率会有一些差距
    • 稳定性会有一些影响
  • 满血渠道：与官方 API 能力完全对等（Claude Coding Plan / AWS Bedrock），模型行为与官方控制台一致，不存在被污染或降智问题，稳定性显著高于逆向渠道。
团队稳定版的"AWS 拖底"是什么？

团队稳定版在主渠道出现异常时，自动切换到 AWS Bedrock 官方合作渠道兜底。AWS Bedrock 是 Anthropic 与 AWS 官方合作的直连渠道，是当前稳定性最高的接入方式，因此该档位价格也相对更高。

并发路数是什么意思？会不会经常排队？

并发路数指同一时间可以处理的请求数量上限。档位越高并发越多：个人性价比/稳定版 3 路，进阶版 10 路，团队两档 50 路。高频调用或多人共用场景建议选择并发更高的档位，避免请求排队等待。

固定价格还是随负载浮动？

固定价格，所见即所付，不随官方负载或汇率浮动，无隐藏系数。

以上教程基于当前版本 Youtoken 后台界面，如有变化以最新版本为准。
