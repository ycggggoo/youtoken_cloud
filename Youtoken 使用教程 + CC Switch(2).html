Youtoken 使用教程

注册 → 创建密钥 → 选择分组 → 配置 Claude Desktop → 用 CC Switch 管理 Claude Code

注册账号 创建密钥 选择分组 配置 Claude Desktop CC Switch 接入 常见问题
⚠️开始之前请确认：
• 已安装最新版 Claude Desktop（低版本可能没有开发者模式入口）
• 第三方 API 使用的是 Anthropic-compatible 协议，不是 OpenAI-compatible
• Gateway base URL 需要是 HTTPS 地址
🧭两条接入路径，按你用的客户端选：
• Claude Desktop（桌面 App） → 走第 4 节的 Developer → Configure Third-Party Inference
• Claude Code（CLI / IDE 插件） → 走第 5 节的 CC Switch，一键导入、多供应商随时切换
两者互不冲突，可以同时配好，用哪个开哪个。
1

注册账号并输入邀请码

第一步是注册 Youtoken 账号，获得使用资格。

a打开注册页面

访问 Youtoken 官网，点击页面上的 「注册」 按钮，进入注册流程。

b填写注册信息

输入你的邮箱地址，设置密码。建议使用常用邮箱，方便后续找回密码和接收通知。

c输入邀请码

在注册表单中找到 「邀请码」 一栏，填入你获得的邀请码。邀请码通常由推荐人或官方活动提供，填写后双方都可获得额外奖励。

💡 邀请码不是必填项，但填写后你和推荐人都能获得返利奖励，建议填上。

d完成注册

点击 「注册」 按钮提交。注册成功后自动登录，进入仪表盘页面。接下来去充值一些余额（支持支付宝），按量计费、余额永久有效。

2

创建 API 密钥

密钥是你调用 API 的凭证，相当于你的专属通行证。

a进入密钥管理页

登录后，在左侧导航栏点击 「API 密钥」（钥匙图标）。首次进入时页面会显示「暂无 API 密钥」。

b点击「创建密钥」

点击页面中央的 「+ 创建密钥」 绿色按钮，弹出创建密钥对话框。

c填写密钥名称

在 「名称」 栏输入一个便于识别的名称，例如 claude-desktop 或 我的主密钥。名称只用于区分不同密钥，随便起即可。

3

选择分组

分组决定你使用的渠道类型、稳定性和价格，是最关键的选择。

a打开分组下拉菜单

创建密钥时可以直接选分组；密钥建好后也能在 「API 密钥」 列表的 「分组」 列点 「选择分组」 随时改。下拉里会列出全部可选分组，每项右侧标注 倍率（倍率越低价格越便宜），下面一行是该档的简短说明。

b根据需求选择合适的分组

不同分组在价格、渠道质量、并发能力上有差异，下面是快速对比：

分组名称 折扣 倍率 渠道 并发 推荐场景
GPT-官方1.4折1.4折1x满血3路GPT 用户首选
claude个人性价比版1.8折1.3x逆向3路预算有限、轻度使用
claude个人稳定版3.5折2.4x满血3路日常推荐，性价比最优
claude个人进阶版4.2折3x满血10路高频开发者
GPT image-2生图—1x满血—GPT 生图需求
grok—0.6x——Grok 模型用户
💡 推荐选择「claude个人稳定版-官方3.5折」：满血渠道、官方直连、支持最新模型和 Web Search，是稳定性与性价比的最佳平衡。如果预算紧张可选 1.8 折性价比版，但注意该档是逆向渠道，不支持 Web Search 且可能偶发不稳定。

c确认创建

选好分组后，点击 「确定」 完成密钥创建。系统会生成一串以 sk- 开头的密钥字符串。

⚠️ 请立即复制并妥善保存密钥！密钥只会显示一次，关闭后无法再查看完整内容。如果丢失只能重新创建。
4

配置 Claude Desktop

把 API 地址和密钥填入 Claude Desktop，即可开始使用。

a启用开发者模式

还没装的先去官网下载：https://claude.ai/download（提供 macOS / Windows 桌面版；macOS 也可用 brew install --cask claude）。务必装最新版，旧版本没有开发者模式入口。

打开 Claude Desktop（建议先保持 未登录状态，已登录的建议先退出）。

  • 在顶部菜单栏选择 Help（帮助） → Troubleshooting（疑难解答）
  • 在弹出的子菜单中点击 Enable Developer Mode（启用开发者模式）
  • 启用成功后，顶部菜单栏会多出一个 Developer（开发者） 菜单
💡 如果找不到菜单按钮，可以按键盘 Tab 切到左上角菜单区域，再按回车打开。

b打开第三方 API 配置

点击顶部新出现的 Developer 菜单，选择 Configure Third-Party Inference…（配置第三方推理…）。

c填写配置信息（最关键一步）

在弹出的配置窗口中，按以下方式填写：

配置项 填写内容
Connection下拉选择 Gateway（Anthropic 兼容网关，不要选 Bedrock / Vertex / Foundry）
Gateway base URL填入平台提供的 API 地址，如 https://youtoken.cloud
Gateway API key粘贴你在第 3 步复制的 sk- 开头的密钥
Gateway auth scheme保持默认 bearer
Custom inference headers一般留空，除非服务商另有要求
Credential kind保持 Static API key

填写完毕后，可先点右上角 Test connection（测试连接） 确认能连通，再点右下角的 Apply Changes（应用更改）。

不同版本按钮文案略有差异：旧版为 Apply locally，新版为 Save Changes / Apply Changes，作用相同。

⚠️ 注意事项：
• API Key 复制时前后不要多空格
• Base URL 必须以 https:// 开头
• Connection 必须选 Gateway（Anthropic 兼容），不是 OpenAI 兼容协议

d重启并验证

配置完成后，完全退出 Claude Desktop 后重新打开（不是最小化，要彻底关掉重启）。

重新打开后，进入 Cowork、Code 或 Projects 相关页面，输入一个简单问题测试。如果模型能正常响应，说明配置成功。

✓ 配置成功后你会看到：
• 模型调用走第三方 API，不消耗 Claude 官方订阅额度
• 可以正常使用 Cowork / Projects / Artifacts 等功能
• 后台可以看到对应的 token 用量和账单
5

用 CC Switch 接入 Claude Code

如果你用的是 Claude Code（命令行 / IDE 插件）而不是桌面 App，用 CC Switch 管理配置最省事——支持一键导入和多供应商秒切。

aCC Switch 是什么

CC Switch 是基于 Tauri 2（Rust 后端 + React 前端）构建的桌面端 AI 编程工具 API 统一管理器，MIT 协议完全开源，可同时管理 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw 五款工具的 API 配置。

对 Claude Code 来说，它做的事就是帮你把 Base URL 和密钥写进 Claude Code 的本地配置（~/.claude/settings.json），并在多个供应商之间一键切换，省掉手动改配置文件、改环境变量的麻烦。

💡 CC Switch 管的是 Claude Code，不是 Claude Desktop。桌面 App 的第三方推理配置仍然按第 4 节操作。

b下载并安装 CC Switch

从 GitHub Releases 页下载：https://github.com/farion1231/cc-switch/releases（官网 https://ccswitch.io）。在 Assets 列表中按系统选择安装包：

系统推荐安装包
macOS（Apple Silicon / Intel）CC-Switch-v3.17.0-macOS.dmg
Windows 10+CC-Switch-v3.17.0-x86_64 对应 exe / msi
Linux arm64CC-Switch-v3.17.0-Linux-arm64.AppImage
Linux x86_64CC-Switch-v3.17.0-Linux-x86_64.AppImage

下载后按正常流程安装，首次启动会引导完成基础设置。

c一键导入 Youtoken 密钥

这是 Youtoken 相比其他平台最省事的地方：不需要跳转确认页、不需要手动核对分组或端点，点一次按钮完成全部配置写入。

  • 回到 Youtoken 的 「API 密钥」 页面
  • 找到第 3 步创建好的密钥，点击操作列的 「导入到 CCS」 按钮（上传图标）
  • 浏览器会通过 ccswitch:// 深链接调起本地已安装的 CC Switch，并弹出导入确认
  • 确认后，CC Switch 的供应商列表中会新增一条对应 Youtoken 站点名称的配置，右侧显示余额和用量
💡 密钥创建时选的分组决定了导入后被识别成哪类应用：claude 系分组（如 3.5 折稳定版）会落到 Claude Code 一侧，GPT 系分组则会落到 Codex 一侧。

d在 CC Switch 中启用该供应商

  • 打开 CC Switch，在顶部工具栏点击 Claude 图标（对应 Claude Code）
  • 在供应商列表中找到刚导入的 Youtoken 站点条目
  • 把右侧开关拨到启用状态

切换即写入配置，后续 Claude Code 的请求就会通过该供应商的接口路由。想换回官方或别的中转站，回到这个列表拨一下开关即可，不需要重装或改任何文件。

e手动添加供应商（备用方式）

如果一键导入没反应，或者站点管理员关闭了该入口，可以在 CC Switch 里手动新建一条 Claude Code 供应商：

配置项填写内容
名称随便起，例如 youtoken-3.5折
Base URLYoutoken 站点的 API 端点地址（https:// 开头）
API Key / Token粘贴第 3 步复制的 sk- 开头密钥

完全不想装 CC Switch 的话，也可以直接给 Claude Code 设环境变量：

# macOS / Linux：写进 ~/.zshrc 或 ~/.bashrc export ANTHROPIC_BASE_URL="https://你的站点地址" export ANTHROPIC_AUTH_TOKEN="sk-你的密钥" # Windows PowerShell $env:ANTHROPIC_BASE_URL="https://你的站点地址" $env:ANTHROPIC_AUTH_TOKEN="sk-你的密钥"
⚠️ 环境变量和 CC Switch 只挑一种用。两边都配的情况下环境变量优先级更高，容易出现「CC Switch 里切了但没生效」的假象。

f验证是否接入成功

新开一个终端窗口（让配置生效），执行：

claude # 进入会话后输入 /status 查看当前使用的 API 端点

随便问一句话，能正常返回即代表接入成功。回 Youtoken 后台的 「使用记录」 页面，能看到刚才这次调用的 token 用量和扣费明细。

✓ 接入成功后你会得到：
• Claude Code 全部功能正常，走第三方 API，不消耗官方订阅额度
• 一套 CC Switch 同时管住 Claude Code / Codex / Gemini CLI，切供应商一次点击
• 后台逐笔可查的 token 用量和账单
6

常见问题

找不到 Developer 菜单怎么办？
  • 确认已点击 Help → Troubleshooting → Enable Developer Mode
  • 完全退出 Claude Desktop 后重新打开
  • 确保 Claude Desktop 已更新到最新版本
配置后还是进了普通 Claude 登录页？
  • 确认 Use this configuration 开关已打开
  • 确认 Gateway、Base URL 和 API Key 都已正确填写
  • 点击 Apply Changes（旧版为 Apply locally）后完全退出并重新打开 Claude Desktop
  • 如果仍不生效，在 Help → Troubleshooting 里查看错误提示
报错或无法连接怎么办？

逐项检查：

  • API Key 是否复制完整，前后不要多空格
  • Base URL 是否以 https:// 开头
  • 平台是否支持 Anthropic-compatible 协议（不是只支持 OpenAI）
  • 余额是否充足、密钥是否处于启用状态
「逆向」和「满血」渠道有什么区别？
  • 逆向渠道：通过第三方账号池间接获取能力，价格最低但可能偶发不稳定，不支持 Web Search，可能存在轻微降智
  • 满血渠道：与官方 API 能力完全对等，模型行为一致，稳定性高，支持 Web Search 等所有功能

日常使用推荐满血渠道的「个人稳定版」，兼顾价格和体验。

CC Switch 和直接填 API Key 有什么区别？

CC Switch 的价值在多工具、多供应商统一管理：一个界面同时管住 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw，换供应商只要拨一下开关，不用去翻各个工具的配置文件。

只用一个中转站、只用一个工具的话，直接填 Key 也完全够用。

点击「导入到 CCS」没反应怎么办？
  • 先确认本机已安装 CC Switch 客户端
  • 已安装仍无反应，检查系统是否正确注册了 ccswitch:// 协议（部分系统首次安装后需要重启一次才生效）
  • 密钥列表里压根看不到这个按钮：站点管理员可能在系统设置里关掉了该入口，属正常配置项，联系管理员开启
  • 都不行就按第 5 节 e 步手动新建供应商，效果一样
CC Switch 里切换了，但 Claude Code 没生效？
  • 重开终端：已经在跑的 Claude Code 会话不会热更新配置，退出重进
  • 检查有没有在 ~/.zshrc / ~/.bashrc 里设过 ANTHROPIC_BASE_URL、ANTHROPIC_AUTH_TOKEN——环境变量会盖掉 CC Switch 写入的配置，删掉或注释即可
  • 确认 CC Switch 顶部选的是 Claude 图标那一栏，别切到 Codex 那边去了
提示 model not supported 怎么办？

检查密钥所在分组是否为 claude 系（GPT 分组的 Key 不能给 Claude Code 用），以及该分组下实际可用渠道支持的模型名是否与请求的模型一致。可在 Youtoken 后台的渠道 / 分组页面核实。

想切换回官方 Claude 怎么办？

Claude Desktop：在 Developer → Configure Third-Party Inference 中关闭 Use this configuration 开关，然后完全退出并重新打开，即可回到官方登录入口。

Claude Code：在 CC Switch 的供应商列表里把 Youtoken 那条开关关掉、切回官方配置；如果是手动设的环境变量，删掉 ANTHROPIC_BASE_URL 和 ANTHROPIC_AUTH_TOKEN 后重开终端。

Web Search 不好使怎么回事？

仅满血渠道支持 Web Search。逆向渠道（1.8 折性价比版）因为无法接触 Anthropic 服务器端的搜索集成，所以不支持真正的 Web Search。如果你需要联网搜索能力，请选择 3.5 折及以上的满血渠道分组。

怎么计费的？大概花多少钱？

按 token 精确计费，输入、输出、缓存分别计价，账单可逐笔核对。无月费、无订阅，余额永久有效。

粗略参考：轻量使用（日常问答）月消费几元到几十元；重度开发者可能几十到上百元，但相比官方原价依然省下大头。

以上教程基于当前版本 Claude Desktop 与 CC Switch v3.17.0，如界面有变化以最新版本为准。
桌面 App 配好后推荐先用 Cowork 或 Projects 试试手；Claude Code 配好后直接在项目里跑一轮就知道通没通。
