接入使用

怎么接入？支持哪些客户端？

与官方 API 完全兼容，只需替换 base URL 和密钥即可。

  • Claude Code：设置 ANTHROPIC_BASE_URL 和 ANTHROPIC_AUTH_TOKEN 环境变量
  • Codex CLI：按官方文档配置自定义 provider，填入我们的 base URL
  • 任意 OpenAI SDK / 兼容客户端：直接替换 base_url 与 api_key
  • 也支持通过 API Key 直接调用，无需额外 SDK
需要科学上网吗？

不需要。国内直连，无地区限制，无需 VPN。

支持哪些客户端工具？

Claude Code、Codex、Gemini CLI，以及任何走 Anthropic/OpenAI 协议的 IDE 插件、Agent 框架均可直接接入。

"逆向"和"满血"是什么意思？

指模型能力的技术来源不同，直接决定稳定性和使用体验：

  • 逆向渠道：通过第三方账号池或客户端接口间接获取模型能力
    • 存在第三方 system prompt，表现上会存在降智现象
    • 缓存命中率会有一些差距
    • 稳定性会有一些影响
  • 满血渠道：与官方 API 能力完全对等（Claude Coding Plan / AWS Bedrock），模型行为与官方控制台一致，不存在被污染或降智问题，稳定性显著高于逆向渠道。
团队稳定版的"AWS 拖底"是什么？

团队稳定版在主渠道出现异常时，自动切换到 AWS Bedrock 官方合作渠道兜底。AWS Bedrock 是 Anthropic 与 AWS 官方合作的直连渠道，是当前稳定性最高的接入方式，因此该档位价格也相对更高。

并发路数是什么意思？会不会经常排队？

并发路数指同一时间可以处理的请求数量上限。档位越高并发越多：个人性价比/稳定版 3 路，进阶版 10 路，团队两档 50 路。高频调用或多人共用场景建议选择并发更高的档位，避免请求排队等待。

固定价格还是随负载浮动？

固定价格，所见即所付，不随官方负载或汇率浮动，无隐藏系数。

功能支持差异（逆向 vs 满血）

不同渠道对 Claude Code 内置能力的支持程度不一样，选购前建议确认清楚，尤其是 Web Search。

Tool Use / Function Calling 支持吗？

支持，所有档位均可正常使用。协议层能把请求转换成 Anthropic 格式，Claude Code 里正常调用工具没有问题，逆向渠道也不例外。

MCP（Model Context Protocol）支持吗？

支持，所有档位均可正常使用。MCP 是客户端侧协议——Claude Code 在本地拉起 MCP server，模型只负责决定调不调用，跟后端是不是逆向渠道无关，因此不受渠道类型影响。

Web Search 支持吗？（重点，坑最大）

仅满血渠道支持，逆向渠道不支持或名不副实，这是两者差异最大、也最容易被忽略的一点。

原因：

  • WebFetch：模型吐出 tool_use 后，由 Claude Code 本地发起 HTTP 请求抓取网页——这是纯客户端行为，逆向渠道也能正常跑通。
  • WebSearch：模型吐出 tool_use 后，是由 Anthropic 服务器端自行调用 Google/Bing 等搜索 API 返回结果——这是官方后端集成的能力，逆向渠道只做协议转发，接触不到这段服务器端逻辑，因此无法真正执行。
  • 逆向渠道遇到 WebSearch 请求时，通常表现为直接报错，或静默降级为 WebFetch（看起来能用，实际检索不到真实结果）。

鉴别方法：需要联网搜索最新信息的场景，直接测试 WebSearch 能不能返回真实检索结果——能正常返回的是满血渠道，报错或结果明显不对的是逆向渠道。本站逆向分组（个人性价比首选）对应存在此限制，其余满血档位不受影响。

充值与计费

最低充值多少？有月费吗？

无月费、无强制订阅。按量付费，用多少付多少，余额永久有效不过期。

支持哪些支付方式？

支付宝，充值即时到账。

怎么计费？是按请求还是按 token？

Token 级别精确计费，输入、输出、缓存读写分别计价，账单可逐笔核对，不会按请求整体估算导致多扣费。

余额会过期吗？能退款吗？

余额不过期。退款政策请以具体客服说明为准（涉及资金操作建议提前确认）。

稳定性与安全

会不会被封号/限流？

多账号池 + 智能调度，单账号异常自动切换，支持粘性会话保证多轮对话上下文一致。国内直连账号不受地区限制影响。

并发高会不会排队很久？

支持用户级和账号级并发控制、可配置速率限制，套餐档位越高（如团队稳定版）资源优先级越高。

我的对话内容会被记录或用于训练吗？

对话内容仅用于处理你的请求，不用于训练，请求日志按平台隐私政策保留必要时长。

账号安全怎么保障？

支持可选的两步验证（2FA/TOTP），API Key 可随时吊销重新生成。
